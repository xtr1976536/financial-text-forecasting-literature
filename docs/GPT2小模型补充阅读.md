# GPT-2 规模的小模型，能否获得强预测能力？

本页整理第二轮追问中新增的论文，完整目录为 F421–F427；不替换第一轮 F001–F420 的稳定编号。

|编号|研究|与问题的关系|
|---|---|---|
|F421|One Fits All / GPT4TS，NeurIPS 2023|冻结六层 GPT-2，适配连续时序输入和预测头；通用时序正面案例。|
|F422|TEMPO，ICLR 2024|分解趋势/季节/残差并通过提示适配；公开约 80M 版本。|
|F423|Are Language Models Actually Useful for Time Series Forecasting?，NeurIPS 2024|删除或替换 LLM 的消融对预测能力来源提出质疑。|

|F425|Parameter-Efficient Adaptation…，2026-09|连续片段与轻量适配达到专用模型竞争范围；新预印本。|

金融领域优先联系 F023 的 M2VN：小型 TiMaGPT 新闻嵌入＋数值特征＋对齐损失。预测能力属于整个系统，不能全部归因于小语言模型。

ChronoGPT（F025）虽测试过 124M 等规模，最终系列使用 1.5B；不要把它作为 124M 小 GPT-2 已成功的证据。

最有价值的实验是固定输入、预测头与训练预算，对比随机初始化、冻结预训练、LoRA/部分微调、移除语言模型，以及强纯数值预测器。通用数据的误差改善、金融相对数值增量与成本后可交易优势必须分别报告。
