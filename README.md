## 怎样使用

1. 在技术表或观点表中选一个具体问题，先看锚点论文，再看同一行的反方或限制条件。
2. 打开单篇阅读卡，查看中文导读、原始题名、原文入口、核读层级和证据边界。
3. 正式引用使用原始题名与DOI；不要把中文导读名当作出版方译名。

公开版保留 **96份已核对公开转载许可的PDF**，其余条目提供原始来源入口。公开前获得的个人阅读副本保留在本地，未确认转载许可的副本不放入公开版本。见[全文状态](catalog/FULLTEXT_STATUS.md)和[许可说明](docs/公开全文与引用说明.md)。
